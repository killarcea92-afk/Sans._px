# A Little Something For You 🌹

A cinematic, Istanbul-inspired friendship apology website.

## Folder structure

- `index.html` — the page
- `style.css` — visual design and animations
- `script.js` — petals, reveals, music modal and interactions
- `assets/` — your uploaded photos

## GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder** from this project.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Spotify note

The site uses Spotify's official embedded player for the track you supplied. Browsers often block audible autoplay until the visitor interacts with the page, so the site uses the opening button and a music-player panel rather than pretending background autoplay is guaranteed.

## Replacing photos

If you want different photos later, replace the files in `assets/` while keeping the same filenames, or update the filenames in `index.html`.

## Final character

`assets/erdem.jpg` is the image you supplied and is animated into the final scene. The rose is a lightweight CSS/emoji element so the site needs no external animation library.
